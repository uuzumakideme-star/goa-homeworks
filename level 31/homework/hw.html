2. CSS-ის ტიპების განმარტება და მაგალითები

Inline CSS (ჩაშენებული სტილი)

განმარტება: იწერება უშუალოდ HTML ელემენტის შიგნით style ატრიბუტის გამოყენებით. გამოიყენება კონკრეტული ელემენტისთვის სწრაფი სტილის მისანიჭებლად, თუმცა არ არის რეკომენდებული დიდი პროექტებისთვის, რადგან კოდს ტვირთავს.

5 მაგალითი:

  1. ტექსტის გაწითლება: წითელი ტექსტი
  2. ფონის შეცვლა: ყვითელი ფონი
  3. ფონტის ზომის გაზრდა: დიდი ტექსტი
  4. ტექსტის ცენტრალიზაცია:
    ცენტრში განთავსებული
  5. ჩარჩოს დამატება: ჩარჩოიანი ტექსტი

Internal CSS (შიდა სტილი)

განმარტება: იწერება HTML დოკუმენტის <head> სექციაში, <style> ტეგებს შორის. გამოიყენება მაშინ, როდესაც სტილები ეხება მხოლოდ ერთ კონკრეტულ HTML გვერდს.

5 მაგალითი (კოდის სახით):

  • p { color: blue; } - ყველა პარაგრაფს აფერადებს ლურჯად.
  • h1 { font-size: 24px; } - H1 სათაურის ზომის მითითება.
  • body { background-color: #f0f0f0; } - მთელი გვერდის ფონის შეცვლა.
  • .text-center { text-align: center; } - ტექსტის ცენტრში გასწორება კლასით.
  • div { border: 2px solid green; } - DIV ელემენტებზე მწვანე ჩარჩოს დადება.

External CSS (გარე სტილი)

განმარტება: CSS კოდი ინახება ცალკე ფაილში (მაგ: style.css) და HTML დოკუმენტს უკავშირდება <link rel="stylesheet" href="style.css"> ტეგით. ეს არის საუკეთესო პრაქტიკა, რადგან ერთი ფაილით შესაძლებელია მრავალი HTML გვერდის გასტილვა.

5 მაგალითი (CSS ფაილის ჩანაწერები):

  • .button { background-color: blue; color: white; } - ღილაკის სტილი.
  • .container { border: 1px solid #000; text-align: left; } - კონტეინერის ჩარჩო და ტექსტი.
  • h2 { font-size: 18px; color: #333; } - ქვესათაურების უნივერსალური სტილი.
  • .card { background-color: #fff; border: 1px solid red; } - ბარათის გასტილვა.
  • footer { text-align: center; font-size: 12px; } - ფუტერის გასწორება და ზომა.
